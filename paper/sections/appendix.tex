\section{A Reference Harness in Fifty Lines}
\label{app:quark}

The listing below is \emph{quark}, the reference harness used to argue for each primitive's necessity in \S\ref{sec:primitives}. It is the complete file \texttt{harness/quark.py} from the accompanying repository, without the dependency header. Each function is one primitive. It gives the model a single tool, a shell, and runs commands on the host without asking; it is a teaching artifact, and the production concerns of \S\ref{sec:production} are what it lacks.
