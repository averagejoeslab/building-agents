\section{Related Work}
\label{sec:related}
The loop that harnesses implement goes back to ReAct \cite{yao2023react}. Later patterns live in particular primitives: Reflexion \cite{shinn2023reflexion} in \prim{Control flow} and \prim{Context}, MemGPT \cite{packer2023memgpt} in \prim{Context}, Toolformer \cite{schick2023toolformer} in the model, with the calls still carried out by \prim{Output}. CoALA \cite{sumers2024coala} describes what an agent \emph{is}, as a cognitive architecture, where this paper describes what software an agent is \emph{made of}; its memory modules are design decisions in \prim{Context} and \prim{Output} here, and \prim{Model interface} and the production concerns have no counterpart there. SWE-agent \cite{yang2024sweagent} shows that the agent-computer interface changes performance; in our terms it is a set of decisions in \prim{Output} and \prim{Context}. Anthropic's distinction between workflows and agents \cite{anthropic2024effective} is a property of \prim{Control flow}. \cite{zhang2026stop} argue that harness configuration can account for more variance than the choice of model, and \cite{fan2026empirical} vary planning, the action space and context management, three dimensions that each fall within one primitive; this paper supplies what both assume, a statement of what the harness's parts are.
