1. **HTML measurement first.** I rendered each deck to HTML and loaded it in headless Chromium through Playwright. A script compared each slide's content against the 1280×720 slide box. It flagged Lesson 2 slides 22, 38 and 64, and Lesson 4 slides 42 and 71.
2. **Text positions in the PDF.** `/tmp/bbox.py` ran `pdftotext -bbox` on each PDF. That gives a bounding box for every word on every page. It flagged any word below y=482pt or right of x=901pt, ignoring the page number and header. I picked those limits to keep Marp's padding margins clear.
3. **Pixel check as a second signal.** I rasterised the pages with `pdftoppm -r 48 -gray` and looked for dark pixels in the bottom band and the side margins. It came back clean on the fixed decks.
4. **Testing the checker.** My first "original" was `git show HEAD`, but a commit had landed mid-session that already contained my fixes. That made the pixel check read 0 and look blind. I then rendered `HEAD~1` and ran the bbox check on it. It flagged the four PDF slides above, so the bbox check does catch real overflow. It also showed that slide 64 only overflowed in the HTML preview.
5. **Fix and recheck.** I added a `<style scoped>` block to each slide that only shrinks the font, so no text changed. I re-rendered all ten decks, and the bbox and pixel checks passed on every one.
